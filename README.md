# 📊 Business Intelligence Sales Analyzer

A professional Business Intelligence Sales Analyzer built using Python, Streamlit, Pandas, NumPy, Matplotlib, and MySQL. This application enables users to upload sales datasets, clean and preprocess data automatically, generate actionable business insights, visualize key performance metrics through an interactive dashboard, and export reports in Excel and PDF formats.

The project is designed to simulate a real-world Business Intelligence solution and demonstrate practical data analysis, reporting, and dashboard development skills.

---

## 🚀 Features

- Upload CSV and Excel sales datasets
- Automatic data cleaning and preprocessing
- Handle missing values and duplicate records
- Standardize and validate data
- Calculate key business KPIs
- Analyze sales, profit, customers, products, and regions
- Generate business insights automatically
- Interactive Streamlit dashboard
- Filter data by year, month, region, category, and product
- Interactive charts using Matplotlib
- Export cleaned data
- Generate Excel reports
- Generate PDF reports
- Store analysis information using MySQL

## ⚙️ Installation

1. Clone the repository
git clone https://github.com/your-username/Business-Intelligence-Sales-Analyzer.git

2. Navigate to the project folder
cd Business-Intelligence-Sales-Analyzer

3. Install dependencies
pip install -r requirements.txt

4. Run the application
streamlit run app.py
