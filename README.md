# 📊 Business Intelligence Sales Analyzer

A comprehensive **Business Intelligence and Sales Analytics** application built with **Python, Streamlit, Pandas, SQL, and Matplotlib** that transforms raw sales data into actionable business insights through interactive dashboards, advanced data analysis, dynamic visualizations, and automated PDF/Excel reporting, enabling data-driven decision-making.

---
🚀 Live Demo

🌐 Streamlit App: https://business-intelligence-sales-analyzer-phz8z7psmuzmnh5u3taxpb.streamlit.app/

---

## ✨ Features

- 📂 Upload CSV and Excel datasets
- 🧹 Automatic data cleaning & preprocessing
- 📈 Interactive KPI Dashboard
  - Total Revenue
  - Net Profit
  - Total Orders
  - Average Order Value (AOV)
  - Profit Margin
- 📊 Sales Analysis
  - Monthly, Quarterly & Yearly Trends
  - Region, Category & Customer Segment Analysis
  - Top & Worst Performing Products
  - Discount Impact Analysis
- 💡 Automated Business Intelligence Insights
- 📤 Export Reports
  - CSV
  - Excel
  - PDF
- 🗄️ MySQL Support with Automatic SQLite Fallback

## 🚀 Installation

### 1. Clone the repository
git clone https://github.com/AmitPilkhwal20/Business-Intelligence-Sales-Analyzer.git
cd Business-Intelligence-Sales-Analyzer

### 2. Install dependencies
pip install -r requirements.txt

### 3. Run the application
streamlit run app.py

### 4. Open in your browser
http://localhost:8501
